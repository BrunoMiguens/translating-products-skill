## Evaluate the suite

Start with the [benchmarking overview](benchmarking.md). It directs you to:

- the [controlled PT-PT benchmark](benchmarks/pt-pt.md) for a frozen,
  claim-bearing paired comparison; or
- the [private product-review workflow](benchmarks/product-review.md) for
  regression testing against real product strings without publishing them.

## Contribute and release

- [Contributing](../CONTRIBUTING.md) explains how to add or change a language,
  surface, platform, source adaptation, external integration, or evaluation.
- [Release checklist](release-checklist.md) tracks the evidence required before
  a stable release.
- [`skills-manifest.json`](../skills-manifest.json) is the public inventory and
  source of truth for bundled capabilities.
